# VENOM V2 — REFERENCE MATRIX

Purpose: extract transferable design/interaction principles. Do not copy proprietary source, assets or exact compositions.

## Reference roles

### UTSUBO — real-time creature / production 3D
Use for:
- real-time animal presence;
- cinematic camera;
- lighting;
- shader/material quality;
- app-like transitions;
- performance discipline;
- WebGPU + WebGL fallback mindset.

VENOM translation:
The serpent must feel alive in the browser, not like a decorative video. Rebuild our own geometry/material/animation.

### NOOMO — narrative character
Use for:
- a 3D creature that guides a scroll story;
- reveal → transformation → disappearance;
- object as narrative device, not decoration.

VENOM translation:
Do not reveal the snake fully at once. Establish anticipation through fragments, scale and soundless movement.

### ACTIVE THEORY — atmosphere / depth
Use for:
- cinematic void;
- layered depth;
- subtle particles;
- scene-to-scene continuity;
- interface receding behind experience.

VENOM translation:
Background is not a wallpaper. It behaves like an environment.

### LUSION — WebGL/DOM synchronization
Use for:
- one 3D object staying aligned with HTML sections;
- scroll synchronization;
- coordinated canvas and DOM.

VENOM translation:
Serpent crosses behind/in front of type and media while DOM remains accessible.

### STUDIO FREIGHT / ARGUS LABS — technical mystique
Use for:
- near-black visual field;
- restrained glowing artifact;
- precision grids;
- technical labels;
- cursor-reactive micro-life;
- manifesto framing.

VENOM translation:
The V and serpent are rare high-value artifacts. Lime is an event, not a fill color.

### COMINVI / HOLOGRAPHIK — chapter storytelling
Use for:
- numbered chapters;
- large industrial photography;
- stacked narratives;
- disciplined content density.

VENOM translation:
Cases and capabilities become large chapters rather than card grids.

### OBYS — typography as motion
Use for:
- huge type;
- strict grid;
- controlled brutality;
- scale/spacing as identity;
- type surviving when 3D is absent.

VENOM translation:
The site remains unmistakably VENOM even with the canvas disabled.

### IMMERSIVE GARDEN — premium finishing
Use for:
- transitions;
- restrained parallax;
- case-study polish;
- backstage / technical proof;
- balance between functional content and experimental layer.

VENOM translation:
Every impressive effect must expose craft, not hide weak content.

## Extraction questions per reference

For each site capture:
1. Hero first 10 seconds.
2. First user interaction.
3. Scroll behavior.
4. Header behavior.
5. Type scale.
6. Grid geometry.
7. Main color tokens.
8. Cursor behavior.
9. Particle/background behavior.
10. Scene transitions.
11. Media transitions.
12. 3D rendering clues.
13. Motion durations.
14. Easing signatures.
15. Mobile substitution.
16. Reduced-motion behavior if visible.
17. Loading behavior.
18. What must NOT be copied.
19. Transferable principle.
20. Proposed VENOM adaptation.
