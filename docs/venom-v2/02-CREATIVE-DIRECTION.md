# VENOM V2 — CREATIVE DIRECTION 0.1

## Thesis

VENOM CODE is not a conventional agency.
The site should feel like entering a controlled digital organism: intelligent, precise, dark, alive.

Keywords:
precision / intelligence / tension / control / depth / transformation / execution

Avoid:
cyberpunk clichés / gamer UI / neon overload / random glitch / matrix rain / skulls / literal hacker visuals / green everywhere.

## Visual field

Base:
- almost-black, never flat pure black everywhere;
- graphite/charcoal surfaces;
- off-white text;
- VENOM lime as signal;
- occasional cold metallic highlights.

The lime appears when:
- system is active;
- something is selected;
- the serpent catches light;
- SNAKE is present;
- user crosses an interaction threshold.

## Material language

The serpent should not look like a stock photoreal snake.

Preferred:
- obsidian / graphite body;
- anisotropic or wet metallic highlights;
- subtle micro-scale normal detail;
- dark body lost in background;
- lime iridescence only at grazing angles;
- occasional translucent/data dissolution.

The material must survive darkness. Silhouette + specular movement matters more than texture detail.

## Typography

Two voices:
1. Display — architectural, severe, large, tight.
2. Technical — mono/neutral, small, high-tracking.

Rules:
- display words may exceed viewport;
- line breaks are designed, not automatic accidents;
- max 1–2 large thoughts per scene;
- body copy is short and readable;
- technical labels provide precision but never become decorative noise.

## Grid

Desktop:
- 12-column base;
- edge labels may sit outside main reading column;
- hero deliberately breaks grid with 3D body.

Mobile:
- 4-column logic;
- no desktop composition merely squeezed;
- 3D simplification is intentional.

## Image/media treatment

Cases:
- large single media moments;
- image/video can be partially occluded by type or serpent;
- avoid generic card mosaics;
- captions are technical/provenance-oriented.

## Iconography

Use:
- simple geometric line icons;
- custom micro symbols for VENOM system states;
- V-based marks;
- no chat-bubble-heavy visual language.

## Page atmosphere

The site alternates tension and silence.

Dense scene → quiet void → impact → technical clarity → cinematic scene.

Do not make every screen spectacular. Contrast creates spectacle.

## SNAKE

SNAKE is not a green chatbot widget.

In V2:
- SNAKE is the intelligence layer of VENOM;
- the serpent visual and the AI interface share one identity;
- when narrative reaches AI, physical serpent can dissolve into particles/data/interface;
- SNAKE interaction should feel native to the site, not a third-party bubble.

## Copy direction

Short.
Concrete.
Outcome-first.
No buzzword soup.

Possible hero language families:
- WE BUILD WHAT MOVES BUSINESS.
- INTELLIGENCE. DESIGN. EXECUTION.
- BUILD BEYOND THE EXPECTED.
- IDEAS BECOME SYSTEMS.
- MORE THAN CODE.

Final hero copy is not frozen in this document.
